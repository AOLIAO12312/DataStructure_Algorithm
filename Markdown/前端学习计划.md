## 🧠 每日学习任务详情

### 📅 第 1 天：CSS 高级特性(7.27)

* 理解盒子模型（content, padding, border, margin）
* 理解 `display` 属性（block、inline、flex、grid）
* 学会使用 `position`, `z-index`, `overflow`
* 掌握伪类选择器（`:hover`, `:first-child`, `:nth-child`）
* 推荐资源：

  * [MDN CSS](https://developer.mozilla.org/zh-CN/docs/Web/CSS)
  * B站搜索：“尚硅谷 CSS 教程”前10集

---

### 📅 第 2 天：JavaScript 基础语法（7.28）

* `let / const / var` 区别
* 数据类型：Number、String、Boolean、Object、Array、null、undefined
* if-else / switch / for / while
* 函数声明与调用
* 数组和对象的基本操作（push、forEach、map）
* 推荐资源：

  * JavaScript.info 中文版：[https://zh.javascript.info/](https://zh.javascript.info/)
  * B站：“黑马程序员 JavaScript 基础”

---

### 📅 第 3 天：DOM 操作与事件机制（7.29）

* 什么是 DOM / Node / Element
* 如何使用 JS 操作 HTML：`getElementById`, `querySelector`, `innerHTML`
* 事件绑定：`addEventListener`、常见事件（click、input、submit）
* 表单交互、验证
* 推荐练习：实现一个点击按钮切换样式的页面

---

### 📅 第 4 天：JS 异步编程 + 模块化（7.30）

* 学会使用 `fetch` 请求接口数据
* 异步的本质（事件循环简单了解）
* Promise 和 async/await 的用法
* 模块化简介：`import/export`
* 实战练习：请求一个公共 API 并展示在页面上（如随机猫图）

---

### 📅 第 5 天：Vue 3 入门 + 项目搭建（7.31）

* 安装 Node.js + Vue CLI + Vite
* Vue 文件结构讲解：`App.vue`, `main.js`, `components/`
* `setup()` 函数、`ref`、`reactive`、`data`
* 模板语法：`{{变量}}`, `v-bind`, `v-on`
* 推荐资源：

  * Vue 官网： [https://cn.vuejs.org/](https://cn.vuejs.org/)
  * B站：“尚硅谷 Vue3 入门教程”（选前10讲）

---

### 📅 第 6 天：Vue 组件与核心指令（8.1）

* 组件拆分、props、emit
* 条件渲染：`v-if`, `v-else`, `v-show`
* 列表渲染：`v-for`
* 双向绑定：`v-model`
* 事件处理：`@click`, `@input`
* 实战练习：制作一个简单的 todo-list 应用

---

### 📅 第 7 天：综合练习 + 项目理解（8.2）

* 选一个 Vue 项目（可用模板）

  * 示例：[https://github.com/vuejs/awesome-vue](https://github.com/vuejs/awesome-vue)
  * 或用 vite 创建一个项目
* 跟读并分析组件代码结构
* 修改部分 UI / 样式 / 数据绑定
* 理解开发流程（npm install → 启动 → 修改 → 编译）
